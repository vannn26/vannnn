Tentang Website

Website Jejak Pahlawan Indonesia dibuat sebagai media pembelajaran digital untuk mengenal sejarah dan perjuangan tokoh-tokoh bangsa Indonesia.


Website ini dibuat menggunakan teknologi dasar pengembangan web yaitu HTML, CSS, dan JavaScript. Fitur pencarian dan kartu pahlawan dibuat secara dinamis sehingga data dapat ditampilkan dengan lebih mudah.
